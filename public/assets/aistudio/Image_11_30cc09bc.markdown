## Brand & Style

The design system projects mission-critical precision, cryptographic authority, and cutting-edge neural intelligence. Tailored for cryptographers, embedded systems engineers, and security researchers evaluating ASCON suite permutations against Google Gemma 4 analysis models, the visual language balances clinical instrument clarity with high-contrast futuristic telemetry.

The aesthetic fuses **Futuristic Technical Minimalism** with **Controlled Glassmorphism**:
- Ultra-deep obsidian foundations eliminate eye fatigue during intensive hardware-in-the-loop and benchmark analysis sessions.
- Luminescent neon accents (electric cyan and synthetic violet) serve functional telemetry purposes: differentiating algorithmic states, memory overheads, and neural inference outputs without decorative clutter.
- Structural micro-grids, translucent frosted consoles, and precision boundary lines establish an environment evocative of an aerospace-grade cryptographic workbench.
- Visual weight leans heavily into high density, razor-sharp vector delineation, and zero frivolous ornamentation.

## Colors

The palette operates in strict dark mode, anchored by deep optical blacks and illuminated by synthetic photonic signals.

### Foundation & Surfaces
- **Canvas Base (`#060913`)**: Ultra-dark obsidian navy providing infinite spatial depth.
- **Surface Level 1 (`#0A0F1D`)**: Recessed chassis for sidebars, system trays, and structural grids.
- **Surface Level 2 (`#111827`)**: Standard container and card background, rendering high-contrast separation from the canvas.
- **Surface Level 3 (`#151F38`)**: Elevated panels, hovering inspect-drawers, and active control clusters.
- **Border / Stroke Alpha**: Subtle linear borders utilizing `rgba(0, 240, 255, 0.12)` for standard isolation and `rgba(139, 92, 246, 0.25)` for active neural telemetry panes.

### Signal & Accents
- **Primary Cyan (`#00F0FF`)**: Designates primary system action, real-time throughput rates, bitwise operations, and active ASCON permutation pipelines. Secondary transition state relies on deep electric cyan (`#00A3FF`).
- **Secondary Violet (`#8B5CF6` / `#6366F1`)**: Reserved exclusively for AI coprocessor modules, Gemma 4 telemetry streams, and neural inference explanations.
- **Verification Emerald (`#10B981` / `#00E676`)**: Denotes cryptographic integrity, nonce freshness, valid test vectors, and side-channel resistance verifications.
- **Advisory Amber (`#F59E0B`)**: Flags register pressure, non-constant-time execution warnings, and branch prediction vulnerabilities.
- **Hazard Rose (`#EF4444`)**: Signifies authenticated tag mismatches, buffer leaks, and cycle anomalies.

## Typography

The typographic hierarchy enforces immediate cognitive distinction between conceptual UI navigation, quantitative metrics, and raw cryptographic telemetry.

- **Headlines & KPI Totals (`Space Grotesk`)**: Technical, geometrically tuned structural typeface that conveys modernity and hardware-grade rigor. Used for dashboard widget titles, model performance indices, and top-level analytics.
- **Narrative & System UI (`Inter`)**: Neutral, highly legible humanist-grotesque balancing dense technical terminology, documentation readouts, and model commentary outputs.
- **Hex Streams, Metrics & Registers (`JetBrains Mono`)**: Strict tabular monospace applied to ciphertext streams, initialization vectors, cycles-per-byte benchmarks, instruction traces, and system status badges. Micro-caps formatting (`label-caps`) requires uppercase transformation and widened tracking for instrumentation labels.

## Layout & Spacing

The layout is built upon a 12-column dynamic fluid telemetry grid system, driven by an exact 4px micro-increment scale to support high data density across workbench views.

### Viewport Adaptation & Breakpoints
- **Desktop Workbench (1440px+)**: 12-column layout with `gutter-lg` (24px) and `margin-lg` (32px). Houses simultaneous three-pane workflows: persistent navigation and hardware targets (2 cols), core ASCON cipher pipeline and benchmark graphs (7 cols), and the Google Gemma 4 analysis side-inspector (3 cols).
- **Compact Desktop / Tablet Landscape (1024px - 1439px)**: 12-column layout with `gutter` (16px) and `margin-md` (24px). Gemma 4 inspector switches to an overlay drawer or a collapsible docking tab.
- **Tablet Portrait & Mobile (<1023px)**: Single or dual-column stacked layout with `margin` (16px). Monospace telemetry views gain horizontal touch-scroll tracks without line clipping to protect hash and stream formatting.

### Spatial Rhythm
Component interiors enforce compact padding (`space-sm` to `space-lg`) to maximize visible information density per viewport. Layout modules prioritize structured gaps over whitespace voids, using subtle technical dividing lines instead of excessive margins.

## Elevation & Depth

Visual depth is achieved through layered structural dark tones, semi-translucent glass membranes, and calibrated cyan-violet luminescence rather than drop shadows.

### Surface Tiers & Blurring
- **Base Stratum (Ground)**: Pure `#060913` with an optional 32px technical dot-matrix grid overlay styled at 3% opacity (`#00F0FF`).
- **Standard Panel (0m)**: Filled with `#111827` at 70% opacity, paired with `backdrop-filter: blur(12px)` and a crisp 1px stroke of `rgba(255, 255, 255, 0.06)`.
- **Raised Interactive Pane (1m)**: Filled with `#151F38` at 85% opacity, `backdrop-filter: blur(16px)`, bordered by `rgba(0, 240, 255, 0.2)`. 
- **Floating Modals & Debug Inspectors (2m)**: Filled with `#0A0F1D` at 95% opacity with an exterior perimeter stroke of `rgba(0, 240, 255, 0.4)` and a directional cyan glow: `box-shadow: 0 0 24px rgba(0, 240, 255, 0.12), 0 12px 32px rgba(0, 0, 0, 0.8)`.

### Photonic Border Glows
Active controls and stateful cards employ directional border highlights. Hovering over a benchmark card shifts the static border to a radial gradient sweep tracking the cursor, punctuated by an internal 1px highlight line.

## Shapes

The design system enforces a precision-machined aesthetic with minimal edge rounding (`roundedness: 1`). Soft pill shapes and heavy rounding are prohibited to prevent a casual consumer feel.

- **Micro Elements (Tags, Inputs, Key Badges)**: 2px corner radius (`rounded-xs` / 0.125rem).
- **Core Interactive Elements (Buttons, Metric Tiles)**: 4px corner radius (`rounded-sm` / 0.25rem).
- **Main Structural Panels & Glass Consoles**: 8px corner radius (`rounded-lg` / 0.5rem).
- **Data Terminal Cutouts**: High-level system modules may incorporate chamfered 45-degree diagonal notch details (clip-path corners) on top-right edges to reinforce high-performance instrumentation cues.

## Components

### Buttons & Interactive Triggers
- **Primary Operational (`Encrypt`, `Run Benchmark`)**: Solid `#00F0FF` background, `#060913` text with `Space Grotesk` medium weight, 4px border radius. Hover introduces a laser cyan aura (`box-shadow: 0 0 16px rgba(0, 240, 255, 0.4)`).
- **Secondary Telemetry (`Step Permutation`, `Export Cycles`)**: Transparent background, 1px stroke of `rgba(0, 240, 255, 0.3)`, `#00F0FF` text. Hover fills background with `rgba(0, 240, 255, 0.08)`.
- **Neural Trigger (`Query Gemma 4`)**: Gradient border stroke running from `#00F0FF` to `#8B5CF6`, subtle violet wash on hover with `#8B5CF6` glow.

### Cryptographic Badges & Status Chips
- Height constrained to 20px or 24px. Built on `JetBrains Mono` at 10px or 11px uppercase.
- Structured with an interior glowing status point (4px solid circle) and a 1px border.
- **Verified / Compliant**: Emerald background tint `rgba(16, 185, 129, 0.1)`, emerald border `rgba(16, 185, 129, 0.3)`, emerald label `#00E676`.
- **Fault Detected / Nonce Collision**: Rose background tint `rgba(239, 68, 68, 0.1)`, rose border `rgba(239, 68, 68, 0.4)`, red label `#EF4444`.

### Input Fields & Parameter Registers
- Dark slate fill `#0A0F1D` inset with a 1px border of `rgba(255, 255, 255, 0.12)`.
- Input text rendered in `JetBrains Mono` 13px. Placeholders use muted steel slate (`#4B5563`).
- Focus state triggers an immediate crisp `#00F0FF` border with a subtle 2px glow ring at 15% opacity. Never relies on default browser focus rings.

### Selection Controls (Checkboxes & Radios)
- Square (checkbox) and faceted diamond (radio) geometries with 2px borders in `#1F2937`.
- Checked state fills with `#00F0FF` (or `#8B5CF6` in AI analysis settings) featuring a high-contrast `#060913` mechanical check or center square pip.

### Glassmorphic Metric & Graph Cards
- Dual-tier header structure: Top bar displays micro-caps mono metadata (`CYCLE COUNT`, `S-BOX DELAY`) with auxiliary status dot; main container shows display-scale numeric values with unit identifiers.
- Bottom boundary terminates with a 1px variable opacity edge, framing embedded SVG micro-sparklines, throughput histograms, or state permutation charts.

### Specialized Cryptographic Workbench Components
- **Hex Stream Matrix**: Continuous tabular grid block showcasing 128-bit key/nonce/tag arrangements with byte-level hover targeting and diff-highlight overlays (green for unchanged, yellow for substitution, cyan for permutation shift).
- **Gemma 4 Real-time Insight Node**: Frosted drawer housing streaming neural commentary with markdown formatting, inline assembly snippets, and automated security vulnerability scores.
